# Decision Buddy 🤔

Your personal assistant for making informed decisions!

## Overview

Decision Buddy is a web application that helps you make informed decisions by analyzing your situation and providing:
- **Pros and Cons**: Clear advantages and disadvantages
- **Opportunity Cost**: What you're giving up by making this choice
- **Time Estimate**: How long this decision will take to implement
- **Next Steps**: Actionable steps to move forward

## Features

- Simple, intuitive interface
- Context-aware analysis based on decision type (career, education, financial, relationships, etc.)
- Instant feedback and recommendations
- Clean, modern design

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Anvi-shah17/Decision_Buddy.git
cd Decision_Buddy
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

1. Start the application:
```bash
python app.py
```

2. Open your browser and navigate to:
```
http://localhost:5000
```

3. Enter your situation and decision, then click "Analyze My Decision"

4. Review the analysis including pros, cons, opportunity cost, time estimate, and next steps

## Example

**Situation**: "I'm considering a job offer at a startup vs. staying at my current corporate job. The startup offers more responsibility but less stability."

**Decision**: "Should I accept the startup job offer?"

The app will analyze your input and provide relevant pros, cons, opportunity costs, time estimates, and actionable next steps.
